# OpenPixo release-note sources

There are no published OpenPixo release notes yet. Release-note preparation
reads this directory by default; upstream release documents were deleted.

For a future release, author reviewed English and Chinese notes under
`v<release-version>/en.md` and `v<release-version>/zh-CN.md`. The retained
release tooling validates these sources before publication. Public destinations
remain unconfigured until the owner selects a repository and release service.

See [tooling ownership](../../tools/AGENTS.md) and
the release plan (openpixo-internal: `docs/RELEASE-PLAN.md`).
