# Use Electron, React, and TypeScript with Windows as the first release target

OpenPixo will use Electron, React, and TypeScript for its desktop workbench, and the first public release will target Windows. The shared desktop stack preserves a path to other operating systems, while a Windows-first release gives the initial package and acceptance work a concrete platform boundary; macOS is a later validation effort rather than a simultaneous launch requirement. The user explicitly selected this stack and launch target after considering Electron's cross-platform capabilities. Testing resources and delivery dates remain intentionally unset.
