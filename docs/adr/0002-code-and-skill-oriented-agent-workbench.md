# Center the local workbench on code, skills, and in-app agent conversations

OpenPixo will provide a local development workbench for independent game developers, with conversations inside the application and code plus skills as its primary working model. Project asset management and simple image/audio/batch operations through skills support that model. This establishes the product and ownership boundary: the earlier asset-tool-centered platform interpretation would have prioritized provider integrations and generator panels, while the chosen direction prioritizes development-agent execution and useful project context. The accepted first release uses Codex with default access, DeepSeek, and OpenRouter; Claude and OpenCode execution layers follow later. It includes a project-enabled skills/MCP catalog, direct project-folder management, and a lightweight workbench. MCP installation covers configuration, dependency detection, and guidance. A standalone asset-generator suite and ComfyUI remain outside scope. Protocol/configuration details, exact preview formats, and the representative game task are implementation or deferred acceptance work.
