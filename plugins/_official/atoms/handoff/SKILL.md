# Handoff

Prepare a handoff when local project work is ready to review or continue.

## Workflow

1. Identify the completed artifacts and changed files within the current
   task's scope. Use existing project records to establish their provenance.
2. Summarize the result with local entry paths, relevant source inputs,
   validation actually performed, and known limitations.
3. State the remaining work and the next action needed to continue in the
   project. Preserve existing provenance when recording handoff details in
   the project's established format.

## Completion

The handoff identifies where to find the work, what was verified, and what
remains unresolved. Record only actions and outcomes that actually occurred.
