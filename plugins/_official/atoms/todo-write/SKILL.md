# Todo write

For non-trivial work, record a numbered plan with the session's plan tool.
Keep it as an audit trail as the work progresses:

1. Keep todos atomic (one verb per todo).
2. Reorder freely as the picture sharpens.
3. Mark a todo complete only after the matching work is complete.
4. Record blockers and skipped work with reasons.

Use whichever plan tool this session exposes. Keep the plan aligned with
the actual work and completion evidence; the host's execution record can
retain plan updates alongside the turn's other activity.
